色コード、フォント名、余白、行高、アイコンサイズは画像だけで断定しない。上記は見た目の観察であり、内部仕様の推定ではない。

## 機能とデータに関する境界

- 現行アプリでは必要人時・配置人時・不足人時・過剰人時・充足率を予定シフトから算出している。
- 公式の診断スコアの計算式は未確認。独自の100点評価を作って公式と同じと扱わない。
- 現行の分析画面は休憩控除前の予定時間を集計しており、勤務実績や売上に基づく人時生産性とは異なる。
- 診断・人時生産性・部門比較まで同等にするには、指標の定義、算式、必要な入力データ、集計条件を確認する必要がある。

## 忠実な再現に必要な画面資料

1. 管理画面トップとナビゲーションの展開・折りたたみ状態
2. 月間シフト表の全体、セル選択、編集ダイアログ
3. 日別シフト・時間帯別の配置画面
4. 希望提出状況とスタッフ別の詳細画面
5. 分析・診断の全体、絞り込み後、ランキング、チェックポイント
6. スタッフ・店舗・設定画面
7. 保存成功、入力エラー、データなし、権限不足などの状態

スクリーンショット、操作動画、または閲覧可能なデモ環境があれば確認できる。実データの氏名・連絡先は伏せて構わない。認証情報をこの文書に保存しない。

## 実装と確認の順序

1. 参照画面と現行ルートを対応付け、変更対象を確定する。
2. 共通ヘッダー・ナビ・配色・文字・余白・罫線のデザインを揃える。
3. 月間表・日別表・提出一覧・分析画面を参照資料と照合して実装する。
4. 操作状態、スクロール、固定列、ダイアログ、エラー表示を揃える。
5. 同じ表示幅で画像比較し、既存のLINEログイン・提出・権限制御を回帰確認する。
