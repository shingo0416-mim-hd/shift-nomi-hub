# 主な16機能の確認・実装結果

## 対応範囲

機能の存在だけでなく、管理者・スタッフの操作画面、永続化、所属組織の分離、基本的な自動テストを確認した。Rシフト本体のソースコード、独自アルゴリズム、接続先メーカーの仕様は提供されていないため、完全互換・同一性能とは扱わない。

| --- | --- | --- | --- |
| 1. 月間シフト自動作成 | 希望時間・優先度・担当回数で編成 | 店舗／個人の勤務上限、勤務間隔、連勤、月の休日数、避ける組合せ、ヘルプ候補を考慮 | 既存の順次割当方式。大規模な最適化・最短1分の性能保証は未検証 |
| 2. 日別作業自動割当 | 未実装 | シフト内に作業を登録し、資格・習熟度・有効期限・休憩・作業の重複を確認。過去の同名作業の担当回数が少ない人を優先 | 必要人数を満たせない場合は不足を表示。全体最適を保証する方式ではない |
| 3. 希望収集・配布 | 希望入力・修正・締切・提出状況あり | スタッフ本人の公開済みシフト・作業・休憩を確認する画面を追加 | 実際のLINEアプリでの端末確認は未実施 |

## 画面

- 管理者：`/dashboard/workforce`（管理画面の「運用機能」）
- LINE管理者：`/{tenant}/line/admin/workforce`
- スタッフ：`/{tenant}/line/workforce`（希望入力画面の「確定シフト・欠員募集・お知らせ」）
- 分析：既存の `/dashboard/analytics`

管理者の運用画面は管理者権限と2要素認証設定が必要。スタッフ画面はLINEセッションの組織・LINE ID・スタッフID・在籍状態を確認する。

## CSV仕様

UTF-8（BOM可）、最大5MB・5000データ行。見出しと列順は以下に一致させる。日時は日本時間の `YYYY-MM-DD HH:mm`。全行を事前検証し、1行でも不正な場合は全件を反映しない。

```csv
member_id,name,store_id,status
```

人事：`status` は `active` / `inactive`。既存スタッフのみ更新。CSV内で同じスタッフIDの重複は不可。

```csv
external_id,member_id,starts_at,ends_at,break_minutes
```

勤怠：組織と外部IDをキーに更新。再取込で重複を作らない。休憩は勤務時間より短い値にする。

```csv
store_id,interval_start,customers,sales
```

POS：店舗と30分枠の開始日時をキーに更新。分は00または30。未取込の枠をゼロとは扱わない。

CSV出力は数式として解釈される文字列をエスケープする。xlsxは文字列セルとして出力する。

## 独自診断の計算式

`max(0, round(100 × (1 − (不足人時 + 過剰人時) / 必要人時) − min(30, 警告数 × 5)))`

必要人時が0、または勤務時間未設定がある場合は点数を出さない。独自の配置状態の指標であり、法令への適合・個人の能力を表すものではない。

## 適用・運用

追加マイグレーション：

- `2026_09_29_000001_create_workforce_operations.php`
- `2026_09_29_000002_add_workforce_delivery_retries.php`

未適用の環境では `php artisan migrate` を実行する。既存テーブルは削除しない。

LINEの予約通知は `workforce:deliver-messages` をスケジューラから毎分実行する。LINE公式アカウントとアクセストークンの設定が必要。端末が通知を受信したことはAPIの受付成功だけでは保証できない。

再送仕様は [LINE公式ドキュメント](https://developers.line.biz/ja/docs/messaging-api/retrying-api-request/) を参照。永続化したリトライキーで重複受付を防止し、最初の送信から23時間以内・最大6回の試行に制限する。5xx・通信例外は間隔を増やして再試行し、4xxは自動再試行しない。設定不備は未配信のまま保持する。

## 検証

自動テストで、管理者／組織別権限、スキルと資格期限、休憩、個人勤務条件、避ける組合せ、欠員応募・承認、組織を越える応募の拒否、既読、送信済みの重複配信防止、CSVの一括検証・再取込、xlsx構造、履歴推定、実データに基づくPOS予測、診断の欠測処理を確認。

完全な機能同等性、接続先製品での実機試験、実際のLINE端末での操作、大規模性能、ブラウザでの視覚検証は未完了。
